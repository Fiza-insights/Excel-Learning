# 📊 Sales Data Analysis & Visualization Project

A comprehensive Excel learning and data analysis repository created using **Microsoft Excel / WPS Office**. This project covers end-to-end data processing, summary techniques, and dynamic data visualizations.

---

## 🚀 Key Learning & Features Covered

### 1. Data Summarization & Pivot Tables (Day 1)
* **Pivot Table Analysis:** Solved 15+ practice tasks analyzing regional sales, distribution channels, and product category performance.
* **Data Formatting:** Applied standard currency formatting (`$`), clean table alignment, and structured data layouts.
* **Workbook Management:** Structured dedicated worksheets (`Sales Data`, `All pivot tables`, and `Practice Tasks`) for clean organization.

### 2. Data Visualization & Charts (Day 2)
* **Monthly Sales Trend Analysis:** Built multi-variable Line and Area charts to track "Product Sold Per Month" across various items.
* **Comparative Category Visualizations:** Created Bar and Column charts for side-by-side product comparisons over time.
* **Proportional & Distribution Charts:** Designed Pie and Doughnut charts to display monthly product sales percentages and market shares.
* **Chart Customization:** Configured legend positioning, axis scales, color schemes, and chart elements for clear visual reporting.

## 📁 Repository Files

* **`Pivot Table.xlsx`** - Contains raw sales dataset, data formatting practice, and 15+ solved Pivot Table analysis tasks.
* **`Excel Charts Tutorial File.xlsx`** - Contains comprehensive data visualization sheets featuring Column, Line, Area, Pie, and Doughnut charts analyzing monthly sales performance.
